# v16 原第五折验证：目标与约束

目标：将v15潜变量读写记忆网络推进到原始第五折，实际核对替换SW后的三通道总分。预定义两个从头训练的候选：原64维TCN控制与原样v15 latent；不在此批修改损失、网格、结构宽度或搜参。

64口训练井拟合所有预处理、SW支持格及初始先验，16口原第五折井只用于早停、选模与最终评分；原行序、九曲线及206维特征保持。Q=1、按点监督；不得加载内层48井checkpoint继续训练。POR/PERM保持已有私有模型，不共享可学习参数。

训练normal CUDA环境、最多2个GPU任务，max80/patience18/min10、batch64、64步每轮、AdamW6e-4/weight_decay0.01、cosine到1e-5。保存原子当前状态含模型、优化器、调度器、RNG和停止计数。启动/恢复须显式；不补原其余四折、不覆盖旧交付。

TCN与latent参数量不同，此批是原第五折的候选比较，不是等容量的机制因果消融。第五折参与选模，不是独立盲测。结束后从磁盘重载两个SW和固定POR/PERM检查点，按实际预测合并评分；无收益时保留已有方案。

维护PROJECTS.md，记录目标、已做、计划、未做以及达成目标之后的选项；每批完成后更新。维护本研究METHOD/FINAL、每实验README、EXPLORATIONS和DL图谱，明确运行中与完成分数。
