# v26：三个目标的输出因子分别优化

目标：直接从已验证80.295581058278配方出发，分别优化POR/PERM/SW的不同输出头，保留每目标的真实增益后实际组合。

预定义11项：POR gate/weight/scale；PERM和SW各gate/weight/location/scale。POR已采纳v25位置修正，本批不重复堆叠同类位置头。旧骨干、校准、路由、已有全部输出参数冻结，新幅值条件小头只修正一个专家输出因子。每个候选独立新参数/优化器/调度/早停/最佳检查点；同一目标复用一次冻结特征计算节省开销，不共享可训练参数；三个目标各用自己的冻结模型。

共同输入为原128维专家隐藏特征与v20的63维幅值统计，191→32→1或8。输出层零初始化。门控、分量权重logit、原始尺度参数的新偏移界为0.25；位置偏移界为0.25倍原分量标准差。只改变一个专家输出因子；门控变化会经hurdle混合联动合成分布的权重，不能声称合成权重不变。所有边界预先固定，不扫系数。

沿用原64训练井/16验证井、九曲线206主输入、冠军预处理/Q50、目标混合似然/3、256点窗口/中央128监督、256格/800动作单覆盖解码。新头lr3e-4、AdamW wd.01、clip2、cosine80×64到1e-6、max80/patience18/min10、batch64×64步。源模型始终eval。仅本目标标签进入其损失。

最多2个normal CUDA进程；目标显式分批启动，未启动任务不排队，无其他原折、冷启动、扩容、旧任务或交付覆盖。每目标最后只能选择一个完整候选或原模型；不将单因子增益直接相加、不作逐井/逐行真值选模。
