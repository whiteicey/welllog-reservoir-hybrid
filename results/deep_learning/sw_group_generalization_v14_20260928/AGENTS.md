# 本轮目标与约束

目标：在原64训练井内部检验跨井泛化，并比较按点与按井均衡的监督权重。初始阶段只做一份固定48井训练/16井内层监控切分；原第五折16井不进入该阶段模型或缓存。

不得复用曾看过内层监控井的旧模型、质量权重Q或目标统计。原九曲线和206维固定特征语义保持，缺失插补、标准化、目标格和标签先验均仅拟合当前训练井。Q=1；井权重属于学习权重，不能叫异常标签置信度。

两候选为point与well，采用相同TCN、初始化、随机窗口、80/18/min10预算和原SW评分，最多2GPU。禁止自动排队、恢复旧任务、补其他原始折、覆盖已交付文件。内层监控用于早停，不能称独立盲测或完整嵌套交叉验证。
