# v36 检索平滑门控修正

目标：修正v35硬截断门控进入负半轴后失活的问题，检验跨井参考密度在可学习门控下是否提供SW增量。v35训练已完成且来源不改；本批为两个独立matched/shuffled修正版，不是重复执行旧脚本。

约束：原v31/v34保留模型TOTAL80.33651343681649不修改。只更新SW检索分支，POR/PERM、SW默认概率及原骨干、原头均冻结。复用v35固定4096参考/Top16候选/27维输入和整井排除；只允许训练井标签进入参考库。沿用Q50、原分折/评分/256格/800动作，max80/patience18/min10/batch64/64steps，最多2GPU进程，无自动队列、补折或旧任务恢复。

方法：alpha=0.25*sigmoid(u+logit(0.04))，初始alpha=0.01；这会改变初始预测，必须真实记录每候选初始分，不能称与原模型初始函数相同。关闭检索才精确复现父模型。两项新候选参数与初始化相同、仅参考标签是否在各参考井内打乱不同；打乱候选不可部署。只有真实匹配超过原模型与打乱对照才记录匹配机制的初步收益，不扫描alpha、参考库、K或核带宽。
