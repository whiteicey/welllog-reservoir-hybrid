# 完整模型两两原生分布融合

## 探索重点
按用户要求，对已有完整模型两两进行概率分布联合预测，各头使用一个对所有行固定的权重，检验能否严格超过80.74。最初固定原模型与新种子20261010/11/12共6对；评估期间20261013完成8阶段，保留最初结果并增补4对，最终5个完整模型10对。20261014尚未完成，不参与。假设是不同种子存在分布互补，配置与来源见PLAN.json、AUGMENT_PLAN.json。

## 已探索内容与验证
各头扫描A权重0:0.01:1、B权重1-A，在完整头的官方分数上选固定比例；相同分数优先更高A权重。对原生概率混合应用原官方动作效用argmax；计算上利用动作期望效用的线性性，保持各模型自己的分布支持与输入预处理，动作集合一致。没有连续点预测算术平均、逐行选模或CONT子集选权重。
复用已验证的原模型+seed10缓存，其余9对共享每轮的模型前向计算。各模型按自身SOURCE/父模型构建并加载完整头checkpoint，哈希与实际载入追踪保存；所有原生预测磁盘重载一致，所有网格端点一致，原144665验证行只覆盖一次。CPU分别评分全部网格，再实际组装、保存并重载10份三头预测，分数与选定头分数一致。原有首对结果精确复现80.73516623772511。

## 实际收益
最佳为原模型+20261013：TOTAL **80.863457557382**，相对80.74 **+0.123457557382**；相对旧每头融合80.73516623772511 **+0.128291319656**；相对原单模型80.70612972323806 **+0.157327834143**。
三个头原模型/新模型权重分别POR0.56/0.44、PERM0.44/0.56、SW0.68/0.32；各头分数78.23303953551347、89.74367648664987、74.23788264685729。同一最佳配对等权0.5/0.5也有 **80.840351605081**，三头共用0.58/0.42为 **80.845166532716**。因此超过80.74在等权设置下也出现，最佳配对选择仍使用同一第五折。
连续子集与原模型相比：POR -0.248553617806、PERM +0.168665049892、SW -0.480118282476。不能把总体提升解读为三个头连续值都改善：POR/SW连续分反而下降，PERM连续分提升。具体DEFAULT/CONT行数与分数见FINAL.json和GAIN_INTERPRETATION.json。

全部10对的等权、共用权重、独立头权重总分及比例见[RESULTS.md](RESULTS.md)；完整网格见WEIGHT_SCORES.csv；原生重放与耗时见各头GPU_FINAL.json。固定第五折调参诊断，尚未独立验证泛化或完整五折OOF；不自动采用为单模型配方或补其他折。每对使用两套8阶段模型、共16个历史训练阶段，本次新增训练阶段为0。原交付与当前8阶段单模型保留。

## 不值得继续的点及证据
这一固定模型集合与0.01网格中，仅原模型+seed11/12/13三对超过80.74；其余7对不值得继续细扫权重，具体排名见RESULTS.md。这只关闭这些配对在当前网格上的进一步扫描，不泛化为不同种子融合无效。不细化到0.01以下，不增加逐行/CONT权重、学习路由或新训练阶段。POR/SW连续值瓶颈没有被本次融合解决；下一步可保留有效单模型训练路线并继续当前最后一个种子，独立泛化/完整OOF仍未完成。

## 耗时与并发
6个GPU头进程报告耗时合计 246.635秒，分别包括加载、数据准备、预热、共享前向、网格与写盘；单进程峰值最大 2681.761MiB。CPU全部评分/选权重/组装/磁盘读回 37.745秒。同等10对工作的研究墙钟 657.116秒，包含入口实现、准备、训练交接等待与评估；不是独立吞吐基准。GPU评估逐头串行，最多与一个训练进程并发，总GPU任务上限2；实际重叠seed13/SW351和seed14/SOURCE，在训练输出中保存V368_CONCURRENCY_ADDENDUM.json，冻结TIMING.json的solo字段不能当作这段工作的孤立耗时。没有为了评估停止或重启训练。
