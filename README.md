## 关键观察：OOF提高，A榜反而下降

此前旧版本完整OOF为 **81.891019（约81.89）**，用户反馈A榜约 **83.92～83.93**。最新一轮尝试的完整OOF最高记录达到 **82.194651（约82.19，逐折调权诊断）**，但实际反馈的A榜只有 **83.61（约83.6）**。

需要区分：A榜83.61对应双种子50:50等权提交，其完整OOF为 **82.174383**；82.194651来自逐折逐头选择最佳融合比例，不能直接当成该提交的独立验证分数。旧版83.93与新版83.61均来自用户反馈，未独立读取榜单。

这组对照说明，当前开发验证上的提升尚未转化为A榜收益。掉分原因尚未定位，不能直接归因于分布输出接口；后续应分别对照训练链路、阶段精简、新增分支、种子融合及按井泛化表现。继续保留旧版作为已知A榜最佳基线，不仅按OOF排名替换提交方案。

## 现有思路与已实现机制

输入GR/PE/SP/CAL/AC/DEN/CNL/RXO/RT，固定206维特征，部分头额外63维幅值统计；排除DEVI/AZIM/BIT/CASE及衍生。统计只在训练井拟合，测试输入只转换。

- 多尺度序列骨干结合局部交互、全局patch通信与井条件。保留有效来源，尝试私有骨干、低秩交互和残差修补。
- 三头独立损失/优化器/早停/选checkpoint，固定组合实际评分；分开分析默认状态与连续值。
- 旧模型输出默认概率和混合分布参数；新头保留混合先验，加入概率格、CDF/RPS监督及有限修正。POR保留训练匹配的Student-t/Cauchy族。
- 当前末级为POR深度/曲线耦合、PERM低秩交互、SW井条件/潜变量/频谱修补，各头新增一阶段，优先小模块或加性改动。
- 先计算共同候选动作期望效用，五折等权后argmax；不平均解码值、不按行或真值选模型。保留256格、800连续动作加默认动作。
- 训练点持续冲突质量权重不把所有困难点当异常；按井隔离，不使用树预测、测试标签、伪标签或外部发布权重。

8阶段链路：来源、POR113、POR151、PERM154、SW104、POR341、PERM336、SW351。两个种子合计16历史阶段，不能说整套仅8阶段。旧v97为来源预训练加18后续阶段。新旧不仅是接口差异，冻结源码/配置/历史哈希保持。

## 未来设想（尚未启动）

1. **定位泛化掉分**：核对来源初始化、训练链路、预算、最优状态和预处理统计，固定对照一次换一个头/阶段。当前保留先验不等于旧包。
2. **强化连续表征与读出**：部分POR/PERM阶段增益偏默认状态；分别报告DEFAULT/CONT和按井成绩，检验RPS系数及保持先验的加性修正。
3. **有效骨干增量修补**：保留主分支，小型残差编码/预测残差支路，配合容量/dropout对照，优先PERM；单次负结果不泛化为整类结构无效。
4. **阶段压缩实测**：相邻checkpoint增益不等于删阶段后下游重训收益，固定父状态/预算/种子，先第五折再授权补折，不承诺无损8→5。
5. **减少选择偏差**：训练井内分组对照，多种子报告稳定性，预先固定比例，减少反复用第五折和榜单选方案，保留负结果。
