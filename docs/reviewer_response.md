# 审稿意见回复摘要

## 意见 1：纯数据拟合与仿真/现场边界

已将研究明确界定为**基于实测测井曲线和解释标签的离线、回顾性基准研究**。两层数据均来自真实井，不是纯仿真；合成扰动仅作敏感性探针。正文明确说明：未开展前瞻性现场试验或在线闭环部署；岩石物理派生特征、目标范围和状态语义不等同于完整物理约束；离线分数不能证明现场物理有效性或操作性能。

## 意见 2：增益有限、可迁移性及超参数敏感性

新增六面板敏感性分析：

- **融合权重**：冻结基模型，使用原有单纯形网格和五折选择；POR、PERM、SW 的树权重分别为 1.00、0.75、0.50，折间稳定。
- **内部阈值**：逐一扫描 89 个候选阈值；仅 60.7%、64.0%、21.3% 的阈值使 POR、PERM、SW 完整配置高于 v2，明确 SW 的阈值依赖性。
- **外部权重**：扫描 0、0.1、0.2、0.35、0.5、0.7、1；0.1–0.5 在五折均优于零外部权重，0.35 折均分最高 82.165，完全外部权重降至 81.908。
- **分箱数**：PERM 30/60/120 分箱均使用相同五折、双种子、特征和 1,200 次迭代。得分分别为 0.89662、0.89689、0.89650；60 分箱在四折和 92.4% 的井 bootstrap 中排名最高，但增益非单调且差异很小。
- **公开阈值**：19 个阈值中 18 个优于未门控树；后验最优 0.45 与记录值 0.5 的 RMSE 仅差 0.000069。

所有后验扫描均明确标注为敏感性分析，不作为新的独立盲测。

## 意见 3：代际加法比较与严格消融

正文已将 v1–v4 表述为代际比较，并新增冻结基模型条件下的受控融合 LOMO：相同折、候选网格、阈值搜索和 HMM-off 协议，内折选择、外折评价。

受控完整配置与原结果的总分差为 2.8×10⁻⁶。完整−消融的总分效应为：

- 树分布：1.3100 [1.1127, 1.5092]；
- 序列门控：0.2718 [0.2249, 0.3239]；
- 序列分布：0.1268 [0.0588, 0.2063]；
- 联合状态门控：0.0404 [0.0133, 0.0692]。

目标层面存在中性结果：POR 的联合门控效应区间跨零，POR 的序列分布效应严格为零，PERM 的序列分布效应很小且区间跨零。2×2 交互的综合效应仅 0.0132 [0.0041, 0.0211]，不足以改变模型选择。

同时集中保留 SW 分布无增益、DTW 基本中性、公开 Well 101 门控退化和完整 v4 公共测试退化等负向/中性证据。正文明确承认候选模块的开发期预选择仍可能带来选择偏差，受控矩阵不等于完全消除该偏差。
