# 标签存在性门控外部化：单族 OOF +0.081 的第一个部署级改进（2026-10-18）

## 摘要

在集成/融合/权重汤（soup）等部署组合路线全部被 A 榜"吸收"（OOF +0.13~+0.20 → A −0.04~−0.16）之后，我们转向**单族模型内部的决策结构**，发现：

> 该任务的三个目标都只有约 28–33% 的行带有真实测量标签，其余行存的是"默认标记值"（POR 0.1 / PERM 0.01 / SW 99.9），而官方评分把默认标记当作取值参与核函数。因此模型的**门控**（该行是否为真实测量的二分类）与**值头**（有标签行的分布）共同决定分数，其中门控漏判是最大的可改进项。

把门控"外部化"：用 206 维增强特征训练独立的 GBDT 标签存在性分类器（5 折 well-level 交叉验证），并与深度模型自身的门控在 **logit 空间融合**（权重 0.7 DL + 0.3 GBDT），可将单族诚实 OOF 从 **82.076 提到 82.157（+0.081）**，五折全正，LOFO 诚实 +0.070。

## 1. 结构解剖（为何门控是油水）

以 pl 族 OOF 为例（723,556 行全标注行）：

| 目标 | 默认真值率 | 门控漏判（真值→预测默认） | 漏判行得分 | 门控正确的值行 kernel | 默认行得分 |
|---|---|---|---|---|---|
| POR | 67.4% | 5.45%（39,404 行） | **0.00** | 50.9 | 97.9 |
| PERM | 68.4% | 3.60%（26,046 行） | ≈0 | 75.9 | 97.6 |
| SW | 71.7% | 9.09%（65,779 行） | 7.9 | 21.8 | 98.8 |

- 完美门控的理论上限：POR +2.8 / PERM +2.7 / SW +1.3（合计 +2.2 TOTAL）——但决策级修复（默认槽 utility 偏置 δ、序列平滑/run-repair）全部证伪；
- 标签存在性无法从输入缺测规则推出（曲线几乎全观测），但**区块结构极强**（邻域一致 98.6% vs 基线 56%）——是"曲线可判别+区块先验"的混合任务，属于模型能力问题。

## 2. 外部门控的有效性

- 在**与模型完全相同的 206 维归一化特征**上训练 `HistGradientBoostingClassifier`（仅用训练折，well-level 5 折 OOF），标签存在性 AUC：**POR 0.9811 / PERM 0.9817 / SW 0.9733**；
- 纯外部门控替换（w=0）反而低于 DL 门控（81.855 < 82.076）——两者错位互补，
- **logit 融合**（w=0.7·DL + 0.3·外部）达到 82.157：五折增量 +0.116 / +0.097 / +0.050 / +0.045 / +0.097，LOFO 诚实 +0.070；
- 强化外部门控（500 树/更深）与双 GBDT 集成只到 82.165（+0.008）——该轴确认在 82.16 平台。

## 3. 部署设计（为何这是"单族形态"）

A 榜的历史规律：**只有单族模型的真实提升会被认账，任何"组合类"工件都被吸收**（详见 `utility_fusion_v370_20261017.md` 的教训）。因此本改进刻意保持单族形态：

1. 部署仍为 pl 单族 5 折运行时（模型、特征、解码不变）；
2. 每折附带一个**同折外训练**的 GBDT 门控（fold-f 模型用排除 fold-f 井训练的 GBDT），与每折解码配对；
3. predict.py 在解码前对外部门控与 DL 门控做 logit 融合（w 存在 `runtime/gate/config.json`）；
4. **优雅退化**：若判分环境缺少 sklearn/pickle 依赖，自动回退到纯 DL 门控（= 已实测 A 83.9353 的 pl 行为，不崩）。

## 4. 验证

- 打包运行时在 fold-1/2 held-out 井上**逐位复现**离线测量（f1: base 83.473 → gate 83.589；f2: base 81.547 → gate 81.644）；
- 判分侧仿真：zip 全新解压 + 任意 cwd + 独立进程运行，与交付结果 **287,844 单元格 0 差异**（maxdiff 0.0）；
- 预测改动克制：相对 pl 基线仅 POR 1.15% / PERM 4.69% / SW 2.0% 的行改变，且集中在门控歧义行。

## 5. 对照校准律的预期

单族工件历史偏移 A ≈ OOF + 1.86 ± 0.09（9 个家族工件）。按此，gate 工件预期 A ≈ **84.00–84.02**（pl 基线实测 83.9353，故增量预期 +0.07）。这是本赛程第一次做出"预期压过 84 线"的候选。

## 6. 悬置问题

- 门控增益在 A 榜的转移尚未观测（前两次组合类工件全部被吸收，本形态首次尝试单族+外部评分器）；
- 若 A 侧再次吸收，说明 A 榜 5 口隐藏井的差异不在门控维度，届时只剩"更强基座模型"一条路（训练侧 10 条轴已全部证伪）。
