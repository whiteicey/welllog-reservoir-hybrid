# 效用场级跨血统融合：从 82.076 到 82.280 的诚实 OOF 突破（2026-10-17）

## 摘要

在六条训练轴（赛程/宽度/窗长/增广/SSL 预训练×2/度量对齐）与解码校准轴全部证伪、种子不变性封死组合空间之后，交付级精度提升最终来自**两条部署侧路线**：

1. **多家族效用场集成（mega）**：同一血统的 4 个重训家族 × 5 折，在期望效用场上等权平均 → 诚实 OOF **82.205（+0.129 vs 交付 82.076）**；
2. **跨血统 v370 效用融合（fused）**：在 (1) 的基础上叠加独立血统 v370 的效用场（λ=1.5），→ 诚实 OOF **82.280（+0.204）**。

关键反直觉发现：**预测级线性混合是负增益，效用场级融合才是正确融合层**——这解释了 2026-10-08 时代 E3 融合（v97×v370，OOF 82.213）为何几乎打平单族，也解释了历史上 mix 探针 OOF 增益在 A 榜上的"吸收"现象。

## 1. 测量口径（先自证）

融合评估必须与官方口径逐位可比。诚实 harness 的做法：

- 每折用**该折模型**（仅该折，不做折平均）预测其 held-out 井，行序与 723,556 个全标注行（80 井 well-major 拼接）对齐；
- 每族效用场按**该族 bundle 自身的预处理 centers** 投影到物理动作网格（`kernel_matrix(actions, [DEFAULT]+centers)`）；
- 自证：该 harness 复现官方基准 **v97 = 82.076 逐位一致**（各家族 81.90-82.08 与官方 ±0.02）。

> 曾发现族间 bundle 预处理异构（v97/pl 为旧代 meta，PERM `regression_median`=0.01284；s2/s3 为新代 0.01912）。融合按物理度量核投影，跨预处理异构合法；以单族自身的错误 centers 全局解码会产生假数（曾见 79.33 vs 正确 81.76）。

## 2. mega：同血统多家族效用集成

- 成员：v97 交付锚、pl（伪标签微调）、s2/s3（同配方重训家族）× 5 折；
- 融合：每行每通道 `U_total(a) = Σ_fam U_fam(a)`，argmax 解码（效用场可加性——这是五次折平均的天然推广）；
- 剂量曲线（诚实）：4 族 82.205 / 5 族 82.199 / 6 族 82.194 / 7 族 82.221 → **饱和平台 +0.13±0.02**；
- LOFO 子集选择（留一折选最优家族子集）81.741 < 等权 81.761 → **子集选择在 16 井上过拟合，等权即最优**。

## 3. v370 血统考古与效用级融合

v370 是另一条独立 DL 管线（双种子/五折、atom+mass 结构），资产完好：

- 打包 OOF 预测（723,556×3）→ 复现 v370 单族 **82.195**；
- 历史 E3 融合（v97×v370，预测级规则）**82.213**——仅比 v370 单族 +0.018。

**预测级 vs 效用级的决定性对比**（mega×v370，逐通道 α 扫描，变换空间为 PERM log10）：

| 融合方式 | 结果 |
|---|---|
| 预测值线性混合 | 中间 α 全域负（α=0.5 时 −0.27 TOTAL），LOFO 诚实 82.15 < mega 82.205 |
| **效用场叠加（λ 扫描）** | **单调正、五折全正**：λ=1.5 时 mega3f 82.280 / mega4f+λ2.0 82.296 |

机制直觉：不同管线预测的点值带有各自的门控/默认位结构与系统性相位，平均会破坏度量最优的点；而期望效用场是可加的，argmax(ΣU) 始终对应"证据合成后的最大期望效用"决策。

## 4. 配置扫描（诚实 OOF，官方口径）

| 配置 | OOF | 备注 |

| v97 交付单族 | 82.076 | 基线复现 |
| mega 4 族 | 82.205 | +0.129 |
| **mega 3 族 + 1.5·v370** | **82.280** | 交付形态；码包 ~410MB |
| mega 4 族 + 2.0·v370 | 82.296 | 体积超安全线 |
| mega 2 族 + 1.0·v370 | 82.217 | 紧凑备选 |
| v97 + 0.5·v370 | 82.216 | 极简双系统 |

校准外推（A ≈ OOF + 1.86 ± 0.09）：fused 配置预计 A 榜 **84.14**，P(≥84.0) ≈ 94%。

## 5. 工程：双运行时融合包的构造

- **子进程隔离**：v370 效用导出作为独立子进程运行（其 cloudpickle 图引用同名模块，进程内与 v97 血统共存会污染 `sys.modules`；历史上 E3 包同样以进程隔离方式实现）；
- **临时目录交换**：规范动作网格与效用 npz 经 `tempfile` 交换（首版逐折全存产生 4.0GB 中间件入包事故，修复为折内平均 + fp16 + 临时目录）；
- 融合引擎：mega Predictor 新增 `predict_well_utility`（返回逐行逐通道效用场），主进程读入 v370 效用、`U = U_mega + λ·U_v370`、argmax 后写 result.json；
- 验证：端到端跑通（10 井/95,948 行），与 mega 包预测对比改变率 POR 3.9% / PERM 14.7% / SW 14.5%，**均值偏移 ≤0.05 点**（零均值修正，非系统偏移）。

## 6. 诚实的悬置问题

- fused 的 A 榜读数尚未观测。校准律在 9 个家族工件上是稳定的（+1.86±0.09），但融合类工件是否沿用同一偏移，正是本轮 A 榜探针要回答的问题；
- 历史 mix 探针（v97×unet2，α=0.1）曾出现 OOF +0.08 → A −0.50 的"吸收"反例；该反例的机制假设是**异血统点值混合破坏度量相位**——本工作用效用级融合绕开了该机制，但只有 A 榜读数能最终裁决；
- 若 A 读数落在 83.9-84.0 区间，可进一步尝试 λ 精调（±0.25）与逐通道 λ；若低于 83.9，则融合增益在 A 侧再次被吸收，需回到模型侧继续寻找独立误差源。
