# 集成知识蒸馏回单族：OOF 82.076 → 82.268（2026-10-18）

## 摘要

集成/融合类工件在 A 榜被系统性"吸收"（OOF +0.13~+0.20 → A −0.04~−0.16），而单族模型的知识提升则正常转移（基准 A ≈ OOF + 1.86）。因此我们尝试把**集成知识蒸馏回单族**：以多族集成的 OOF 预测为教师、以交付单族模型为学生，在保持"单族工件"形态的前提下，把集成捕捉到的方差缩减知识固化进单个模型。

结果：honest OOF **82.076 → 82.268（+0.192）**，其中 POR +0.293、SW +0.291、PERM +0.007——超过所有集成工件自身的 OOF（mega 82.205 / fused 82.280），且工件形态是单族。

## 1. 方法

沿用项目已有的伪标签微调管线（`_pseudo_finetune.py`：5 折 GroupKFold、每折以交付 v97 模型初始化、小学习率微调、诚实门控"未提升则恢复原权重"），通过 monkey-patch 替换训练标签构造：

1. **教师** = 4 族 mega 集成的逐行 OOF 预测（每组预测来自未训练该井的折模型，无泄漏）；
2. **手术式标签替换（关键）**：只对"该通道真值存在（非默认标记）且教师也判该通道有值"的行，用教师的点预测替换真值标签；**真值默认标记（0.1/0.01/99.9）原样保留**；
   - 早期"全量替换"版本（连默认标记行也用教师预测）OOF 仅 +0.045，且污染了学生的门控概率面——手术版是决定性修正；
3. 学生初始化 = 交付 v97 五折模型；学习率 LR×25（相对基线 [3e-6,3e-5,1e-5]）、6→20 epochs、patience 3；
4. 每折每通道独立执行，诚实评估使用**真值 held-out 行**，未提升的通道自动回滚原权重。

## 3. 与门控（另一单族改进）不可叠加

门控外部化（GBDT 标签存在分类器与 DL 门控 logit 融合，OOF +0.081）与本蒸馏**互斥**：任何蒸馏后的学生 + 门控融合都退化（w=0.85 → 82.11 < 82.268）。推测原因：蒸馏改变了学生对默认标记的概率面/值分布，与门控决策的边界互斥。两机制需分开提交（各为一发独立候选）。

## 5. 意义与悬置

- 这是本赛程**首次把集成收益无损地固化回单族形态**（+0.192 OOF），绕开了"集成工件 A 侧吸收"的陷阱；
- A 榜转移待观测：按单族校准律（+1.86±0.09）预计 **A ≈ 84.13**，为队史首次"预期显著高于 84 线"的候选；
- 若 A 侧再次吸收，则说明隐藏井的差异不在"值估计方差缩减"维度，剩"更强基座模型"一条路。
