## 5. 候选算法比较

| 优先级 | 方向 | 差异与价值 | 状态 |
|---|---|---|---|
| 1 | POR 概率效用决策 | 同一分箱模型，最大化官方核期望，不取均值/argmax | 已实现，未验证真实增益 |
| 2 | POR 默认值联合质量点 | 默认概率和非默认分布共同参与效用决策，不搜索阈值 | 已实现，校准风险较高 |
| 3 | SW 离散条件分布 | 在 5% 相对容差下决定动作，不直接优化 RMSE | 明确规格，待 H20 |
| 4 | 低自由度目标级非负融合 | 同折、固定小网格、嵌套选择，限制自由度 | 备用规格 |
| 5 | 曲线边缘约束短窗口 | 用输入曲线跳变禁止跨界平滑，不重复普通标签平滑 | 仅探索 |
| 低 | ordinal/quantile ensemble | 损失到效用的转换仍需分布估计，成本高于已有 POR 概率 | 先不做 |
| 低 | 潜在地质 MoE | 80 口井下专家样本不足；原专家失败源码缺失 | 不重新训练 |
| 低 | GBDT + 序列残差/状态模型 | 与纯 TCN 不同，但需严格外层残差及概率缓存 | 暂不投入 |
| 低 | 物理约束/多任务 | Archie 依赖未给定物性，硬约束可能引入系统误差 | 仅代理输入 |
| 低 | test-time normalization/域适配 | 已有井内 rank/QNORM；新域方案缺少收益证据 | 不新增 |

未找到原失败实验具体实现，因此本轮不声称推翻其结论，也不直接重跑这些方向。SW 分布分类的实质变化是目标和决策方式，而不是重新尝试分段专家或加权 RMSE。

## 6. 前五方向的可执行规格

所有资源和增益区间均为**未实测的主观规划值**，不是成绩预测；模型误校准可导致负收益。时间先以 H20 第一折计时修订。

### P1：POR 条件效用决策（首选）

沿用 113 维输入、80 个 log1p 分位数类别、MultiClass、depth=8、lr=0.04、1200 轮，非默认完整有效标签行训练，无额外采样；默认模型 500 轮。概率按种子平均，再用官方核选择动作。默认 gate 在新实验固定 0.5，完整训练一致；不在 OOF 搜阈值。

MVP：5 折单种子 42，argmax/utility 共用概率；通过后 42/2026 双种子复核。已有同口径 OOF 时只重算决策，不训练。难度低；风险是分箱中位数近似和概率误校准。主观总分变化区间 -0.3～+0.6。已有概率 CPU 秒到分钟、内存数百 MB；完整 5 折双种子规划 2–12 GPU 小时、显存 8–32 GB、OOF/模型/日志预留 5 GB。正向 micro/macro 且多数折改善才继续；明显负增益即停止。

### P2：POR 联合质量点

输入/模型/损失/采样完全复用 P1。分布为 `[p_default, (1-p_default)*p_class]`，support 为 `[0.1, expm1(centers)]`。同核效用决策，无阈值和 scale/offset。MVP 与 P1 共用一次 CV，额外算力很低。难度低，默认分类器概率未校准是主要风险；主观总分 -1.0～+0.5。若默认段下降抵消连续段提升，停止，不能对同一 OOF 连续调温度补救。需要校准时只在内层训练井的 OOF 上拟合单温度并在外层评估。

### P3：SW 分布分类

237 维现有输入；默认分类器保持现有结构，首轮固定 gate=0.5 并重新评估基准。非默认 SW 使用训练折 log(SW) 的 80 档分位数，训练 MultiClass 1200 轮/depth8/lr0.04，无相对误差加权。中心为每档 log 标签中位数的 exp；预测使用 SW 5% 三角核。首轮不用 soft labels，不改物理特征、不做专家；由此区分于已失败的平滑/专家/相对权重 RMSE。

同折 RMSE 与分布模型必须共享 gate。MVP 5 折单种子；后续双种子。预计 3–16 GPU 小时、显存 12–40 GB、磁盘 5–15 GB。难度中；高默认占比、宽档近似和概率失准是风险。主观总分 -0.6～+0.6。达不到配对 +0.2 总分或 macro 变差则不扩大；不以训练分类准确率验收。

### P4：非负融合

只混合同折旧基线/入选候选的同目标输出，权重预定 `{0,0.25,0.5,0.75,1}`；PERM 若参与则先 log10，POR/SW 原尺度。不要跨目标/逐井独立调权。外层每折的权重必须由仅外层训练井产生的内层 OOF 选出。MVP 只 POR 一对模型；内层最优与纯候选近似时选简单方案。主观总分 -0.2～+0.3，已有严格内层预测 CPU 分钟级，重训成本可能约 3–5 倍基础 CV。难度中，点值融合落在两峰之间可能变差；95% 配对区间不能排除无收益时不据此提交。

### P5：输入边缘约束后处理

只对非默认连续预测做 3/5 点中位滤波；用 GR/RT/CNL 在本井 IQR 归一化的一阶差超过训练折 95% 分位数作为断层边界，禁止跨边界窗口。阈值从训练输入确定，不从外层标签调。MVP 两个窗口且固定界值，外层比较不滤波；不使用标签生成边界，不使用长窗口。与旧标签平滑实质不同，但原失败实现缺失，优先级最低。CPU 分钟级、内存 <1GB、难度中；主观总分 -0.5～+0.2。任何最差井明显恶化或收益落在噪声内立即停止。

## 7. 首选新算法完整设计

设真实代表值 `y_j=expm1(center_j)`、概率 `p_j`，动作 `a_i`：

`K[i,j] = max(0, 1 - abs(a_i-y_j)/(0.08*(abs(y_j)+1e-5)))`

`a* = argmax_i sum_j p_j K[i,j]`。

分母必须是真值代表点，不是动作；矩阵方向不得颠倒。单类别三角核的峰值在 y_j，边界处斜率只会上升，故离散点质量分布的总效用最大值可以在某个 y_j 取得；不必穷举稠密连续网格。测试用全部峰和支撑边界验证这一点。实现按 4096 行分块计算，避免 N×K×K 广播。

该结论不等于真实标签上的 Bayes 最优：当前只用档中位数近似档内分布，未来如扩大档内代表点，应在训练折采样分位点并重新推导计算/验收。平均两个种子的概率后决定动作，不平均两个已经决定的峰值。默认模式保持与固定 gate 基线一致；joint 单独比较。

## 10. 严格验收

1. 同一折、同一有效行、同一模型概率作决策消融；训练/验证均固定轮数且一致。
2. 同时报告 micro、逐井 macro、最差五井、五折分数/均值/标准差、默认与连续段及标签区间。
3. POR 总分折算 `30*delta_por`，不能冒充完整三目标测量。完整候选需要补充 PERM/SW 同折 OOF。
4. 推进门槛建议：micro 与 macro 同向、至少 4/5 折正向、井级配对区间下界 >0、条件总分增量目标 ≥0.3；最差五井平均不下降。小于折间波动的增益判为不足以支持提交，追加独立 grouped holdout 后再决定。
5. 看过外层结果后不能继续调温度、门控、档数再引用同一外层区间证明泛化。需要 nested CV 或新切分。
6. v3 新训练没有验证结果时元数据明确 `not_evaluated_this_run`。
