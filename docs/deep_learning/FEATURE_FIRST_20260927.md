第一版局部稳健特征在 epoch1 后因 D 盘剩余约1.41GiB、小于探测器1.78GiB临时CDF而中断；该轮分数不参与上表。重跑使用内存中**同精度float32全训练点CDF**，训练的Q更新计算不变，只将最终探测历史改为紧凑末态。完整重跑单任务折内耗时958.42s、GPU峰值1129.83MiB；局部相关901.28s/1099.50MiB，原型路由909.34s/1111.35MiB，原型校准909.62s/1113.39MiB。两个SW头实验部分时间并发，1289.72s与1230.08s分别是各自单项耗时，不能相加当实际总墙钟。资源数字均为训练器报告的单进程分配峰值，不是整机总显存。

本批没有候选达到80.4，因此无新四折训练、无新完整OOF。完整五折最好仍是此前校准双专家 **81.7132331848**，不是上表后验路由的五折结果。提交后的A榜83.6915为用户反馈，不能替代本地OOF验证。

继续手工添加同类局部数值、配对相关或原型侧特征的证据不足；下一轮若恢复训练资源，优先检验**在训练井内学习的跨曲线表征**（例如小型掩码曲线重建预任务或专家内部可学习的跨曲线交互），而不是再扫窗口、聚类数、投影宽度或LR。新方案仍须保持训练井拟合与固定第五折筛选，不能使用测试标签、验证标签训练特征或逐行后验选优。
