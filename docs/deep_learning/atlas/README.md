# 纯 DL 演进图谱

生成后直接打开本地 `index.html`（生成快照不上传Git；下方给出重建命令）。这是可离线使用的单文件 HTML，无 CDN、无需服务器、不会访问训练数据或模型权重。

## 阅读方式

- **关键演进主线**：从简单 CNN、概率预测、多尺度序列，走到双专家、后验路由、投票与当前特征工程。
- **全部尝试**：展示本地留存的每个实验/子配置节点；相似路线在同一个章节内排列。搜索实验名、机制或分数定位节点。
- **Dead ends**：已关闭的路线及其父尝试，说明实测结果、停止原因和结论边界。
- **节点详情**：初步/最终结果、各折口径、机制、来源、父子节点。点击“追溯这条路线”展开祖先和直接后继。
- 拖动画布移动，滚轮缩放，使用缩略图定位。列表提供无需操作画布的替代入口；手机点击列表节点展开详情。

每个节点都显示结果或明确的缺失状态。未训练、原型、启动失败、提前停止与完整结果分别说明。**首折、第五折、完整 OOF、验证集调参不可直接横比。** A榜83.6915为用户反馈，未冒充 OOF。固定第五折重复筛选本身可能产生选择偏差，图中不把小幅单种子改善描述为稳定泛化增益。

布局使用**一行一个主题的泳道**。同主题节点从左向右排列，下游节点始终位于所有上游节点右侧；不同主题之间的分叉、融合用跨行箭头连接。同主题跳过中间节点的边绕过卡片上方，不画出反向或回头箭头。横向位置表达演进先后，不表示分数大小或严格日历时间。

实线为方法演进/源码继承，融合输入另有类型，虚线区分对照、推定和关闭关系；详情显示每条边的类型与证据。源码继承不保证训练预算、输入或损失完全相同。无法确认的父关系保持未连接，并在页面底栏计数。大范围视图可横向拖动或利用缩略图定位，再用“追溯这条路线”缩小范围。

## 覆盖范围与证据

自动读取当前 `outputs/pure_dl_*`、三个初始 CNN/MLP 目录及可识别的子配置。汇总目录和特征审计目录不冒充独立模型；独立诊断/准备/失败启动仍保留状态节点。树模型、v3以及树/DL融合排除。

每个分数记录保存对应 JSON 路径；各模型自己的 README、源码和配置作为详情链接。历史记录若已删除或文本损坏，无法凭空恢复，节点会说明证据不足。部分原始摘录存在历史乱码，人工整理的主线与结论使用中文补充，不篡改原证据。

`atlas-data.json` 保存结构化节点/边；`curate.py` 是人工中文标注与确认关系的维护入口，生成 `curation.json`。`build_atlas.py` 只读取紧凑记录并生成数据和 HTML，不扫描大权重/NPZ，不触碰训练代码。

## 每次尝试后维护

仓库根、工作区根及 `experiments/pure_dl/AGENTS.md` 已加入强制维护规则：新尝试必须登记图谱、初步结果与血缘，结束或转向时更新结论。相似尝试允许归组，但不得丢失子配置结果和来源。

从仓库根运行：

```powershell
# 改动人工摘要/关系后才需要运行这一行
& 'C:\Users\z5364\.conda\envs\normal\python.exe' docs/deep_learning/atlas/curate.py
# 每次新增结果/更新状态后运行
& 'C:\Users\z5364\.conda\envs\normal\python.exe' docs/deep_learning/atlas/build_atlas.py
```

生成的是带更新时间的静态快照，不是实时监控页面。新增目录能被自动登记；新机制仍需要人工补中文解释、确认父关系及停止理由。以后如归并同类实验，需保留展开到子配置的能力和证据。

## 验证

`check_browser.py` 用本地 Edge/Playwright 检查离线加载、搜索、列表/图切换、关系追溯、空搜索、全部节点及手机详情。覆盖1440×900、1366×768、1920×1080和390×844。`browser-check.json` 保存实际结果，`preview-*.png` 为截图；不需要安装新依赖。

```powershell
& 'C:\Users\z5364\.conda\envs\normal\python.exe' docs/deep_learning/atlas/check_browser.py
```

界面文件改动后执行上述验证；只有分数快照刷新时，优先运行数据完整性检查，不重复整套浏览器流程。
