# DL 演进图谱

- 目标：以可追溯的节点和关系总结本工作区所有留存的纯 DL 尝试；排除树模型和 DL/树融合。
- 维护 PROJECTS.md，记录覆盖范围、已做/待做、目标和后续事项。
- 每次新增实验必须更新图谱；先登记机制、父节点、配置、初步结果，结束或改变方向时更新分数、状态和 dead end 原因。相似尝试允许归组，但保留各子实验结果及来源。
- 运行 build_atlas.py 刷新静态快照。新增机制应维护 curate.py 中的中文摘要和明确血缘，再运行它生成 curation.json；自动推定边必须保留推定标识。
- 首折、第五折、完整 OOF、验证集权重搜索不可混排成绩。提前停止不能描述为完整核验，dead end 只约束已测试设置，不宣称方法普遍无效。
- HTML 必须离线打开，不依赖 CDN；节点、关系和结论可追溯到本地记录。源码、数据和生成页面均保留，禁止修改训练源文件。
- 布局遵守用户要求：每行一个主题，同主题向右演进，跨主题以跨行箭头表达分叉/融合。所有边的下游横坐标必须大于上游卡片右边界，路径不得回头；新增主题或关系后验证该不变量。
