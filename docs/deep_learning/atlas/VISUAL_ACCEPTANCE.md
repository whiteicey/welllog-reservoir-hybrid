- 入口：本地 `index.html`，Edge 无头浏览器，真实留存记录，非模拟数据。
- 最终规模：316 个实验/子配置记录 + 8 个路线关闭节点，648 条有向关系。307 个实验节点有数值结果；其余 9 个明确标记诊断、原型、取消、记录缺失或启动失败。47 个实验父关系尚无充分证据，保持未确认。
- 数据检查：节点 ID 唯一；关系端点有效、无自环或循环；所有证据链接在当前工作区存在；分数在有效范围。结果见 `data-check.json`。
- 实际浏览器检查：离线加载无页面脚本错误；直接点击 SVG 节点、键盘 Enter 选择、缩放；搜索→列表→详情→追溯→定位；空搜索；全部节点；dead end 原因及成绩；手机详情打开/关闭。
- 视口：1440×900、1366×768、1920×1080、390×844；无页面横向溢出。图谱自身允许平移/缩放，不以挤小整张图代替可读性。
- 视觉检查：已查看主线、dead end 与手机截图；文字、分数、折口径分层清晰，路线状态有文字说明，详情和图谱同步；高密度全量视图配备章节筛选、缩略图与列表替代入口。
