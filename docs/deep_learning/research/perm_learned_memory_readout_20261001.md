# PERM 可学习原型记忆：文献关系及最小对照

2026-10-01。仅文献研究，不修改训练源码、不启动 GPU、不做独立代码审查。当前事实由主 Agent 提供：井均衡 PERM 有微小正收益，熵风险和多项末端微调未获得明确收益。**这些结果没有证明缺少记忆就是瓶颈。**

## 主来源与概念边界

[Hopfield Networks is All You Need，Ramsauer et al.](https://arxiv.org/abs/2008.02217)，[作者官方实现](https://github.com/ml-jku/hopfield-layers)，[作者说明](https://ml-jku.github.io/hopfield-layers/)。论文事实：现代连续 Hopfield 更新可以写成 softmax attention，文中明确支持访问学习到的原型，讨论全局平均、子集平均和单模式吸引状态。容量/检索误差理论具有前提，不能直接宣称这个32槽模块有指数有效容量或能检索测井岩性。

补充关系：[Set Transformer，ICML 2019](https://proceedings.mlr.press/v97/lee19d)。论文使用学习到的 inducing points 构成两段注意力瓶颈处理输入集合。本方案只有**输入query读取静态学习key/value**，没有“inducing points先聚合当前样本集、再回读”的两段ISAB，也不汇集当前井的样本集合。因此更准确称作“输入条件化的学习原型读出/单步关联记忆”，不是完整Set Transformer，也不是样本检索或数据库。

## 拟定模块

冻结PERM154提供h∈R128；q=Wq h∈R64，K∈R32×64、V∈R32×32均为随机可学习参数。a=softmax(qKᵀ/√64)，m=aV，r=Wout m，h_new=h+b*tanh(r/b)。Wout及其bias初始化0，b按事先固定的hidden尺度定义，scale如需依赖h必须明确是否detach，不在验证标签上选。q/K/V随机且不同槽初始化不相同。

若所有线性包含bias，query8256 + K2048 + V1024 + output4224 = **15552新增参数**；加既有有效mass/background结构12609，联合新增训练模块约**28161参数**，不计可选LayerNorm，实际由实现统计。一阶段从154出发联合训练，不加载已训练memory或mass修补再增加阶段。gate/原父模型/数据和原评分保持既定约束。

零投影使初始预测函数保持，但也导致**第一步query/K/V梯度为0**；投影更新后梯度才通。这是预期的残差热启动现象，不能把第一步无梯度误判为失败，也不能保证此后学习充分。value不能同时全部为0，否则output梯度也可能被阻断。

这个结构的表达偏好是由h选择不同原型值的凸组合，再投影回hidden。它可能提供分段/软聚类式非线性特征，让不同条件区域共享读出修正；这是本任务推测。固定32槽容量、单次读取即可，不增加迭代Hopfield更新或槽数扫参。

## 主推近容量 MLP 对照；uniform只作机制解释

主 Agent 已采纳近容量对照：memory15552参数 vs MLP128→60→128含bias **15548参数**，仅差4，不加dummy；因此写为**near-capacity，不是严格参数match**。共同bound=.25、最后投影0初始化、同12609参数mass/background以及v264井均衡loss，来源154/种子/预算/参数更新范围相同。单因素为字典式softmax读出与两层MLP非线性表征；不再主推uniform作为公平容量消融。

memory query/key/value与MLP首层的第一步梯度均被零末层延迟，之后末层更新才使上游梯度开放。两组初始新增输出0，不把初始函数差异算收益。memory分支属于投影后的latent dictionary，不是完整Hopfield论文复现；即便有益也不声称验证其检索理论。

以下保留uniform控制的局限说明，**不要求启动uniform实验**：

两组使用相同154来源、memory+mass/background结构、随机种子、零投影、井均衡loss、训练预算；唯一分支是a=softmax(qKᵀ/√64)或a_i=1/32。保留同一参数注册以便源码差异聚焦，但必须报告有效性区别：

- uniform组q/K对输出无贡献、无数据梯度；V只有槽均值可辨识，不能把32个value各算成独立有效表征。
- 其投影残差是固定向量，若bound随h的RMS变化，则只是固定方向随一个标量变化；不是等容量非线性函数。
- attention组是输入条件化、可学习选择的非线性函数。所以这是**条件化记忆 vs 常量读取控制**，不是“参数相等的纯attention算法优势消融”。
- 两组初始输出完全相同，可说明后续增益不是初始化函数差异；仍不能消除有效函数容量差异。

memory和MLP为平行候选，不能把MLP串在已训练memory之后增加阶段。memory胜MLP支持“相近容量下字典读出的归纳偏好有益”；两者都只胜父模型而彼此相近，说明新增非线性容量有效，不能归功于原型记忆独特机制。近容量参数计数也不代表优化难度或有效函数族完全相同，应保留这层证据边界。

## 最有用风险与停止标准

1. **读出绕过记忆**：有效mass/background可独自改善，memory不动。记录原父函数、最终目标分、attention-vs-uniform差值；若有必要，训练侧检查新增分支实际输出幅度，别仅凭总loss下降说记忆有效。
2. **槽塌缩或饱和**：全部query近uniform使模块退化，或key范数增长导致硬选择、单槽垄断。训练侧一次记录平均attention熵/槽平均使用率足以辅助解释，不按验证表现增加温度/loss网格，不把低熵自动当错误。
3. **不能补充缺失信息**：冻结h已丢失的曲线/深度信息，静态参数memory不能恢复。它是非线性函数容量，不是外部知识。结果负时换输入/表征方向，不继续槽数升级。
4. **默认状态不一定安全**：即便gate固定，连续分布改变会改变联合动作选择。需恢复目标最佳后实际组合，并报告连续/默认抵消；不能由gate冻结宣称默认分恒定。

完整恢复后memory不胜近容量MLP且不胜保留版本，关闭这32槽单读设计；memory只微胜MLP但整体不提高，明确局部增益，不升级为达标配方。若memory显著有益，再实施一个有明确证据的改动，仍保持每头最多一个新增阶段、总阶段不超过8。只用真实训练标签、无样本标签memory、无teacher/外部预训练，固定第五折严格>80.8有收益后才补其他折。
