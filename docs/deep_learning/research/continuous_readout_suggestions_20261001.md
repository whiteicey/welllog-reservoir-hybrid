# 连续值读出：有界文献建议（2026-10-01）

本记录仅研究，不启动 GPU、读取权重或修改训练源码。当前对照条件由主 Agent 提供：第五折 TOTAL 80.624827；SW 默认状态约 70%；有界 logmass 小头有微小收益，原特征旁路和末端 FF 微调未证明额外收益。目标为保留有效父模型，每头最多一个新增阶段，模块少于 50k 参数。所有下面的收益均**尚未训练证实**。

## 三篇原始来源

1. [Neural Spline Flows, Durkan et al., NeurIPS 2019](https://arxiv.org/abs/1906.04032)。论文事实：以单调有理二次样条构造可微可逆变换，保持解析求逆；用于密度建模。借鉴重点是一个标量变换，**不引入整套 flow 骨干**。[作者实现](https://github.com/bayesiains/nsf)。
2. [Learning Quantile Functions without Quantile Crossing, Park et al., AISTATS 2022](https://proceedings.mlr.press/v151/park22a.html)。论文事实：增量分位数/样条分位数层约束单调，支持任意分位数插值外推，提供 CRPS 的解析计算。借鉴重点是直接监督分位数及非交叉参数化。
3. [Any-Quantile Probabilistic Forecasting of Short-Term Electricity Demand, Smyl et al., 2024](https://arxiv.org/abs/2404.17451)。论文事实：提出任意分位数预测方法，并在两种网络架构和 35 条欧洲电力需求序列上评估。[作者代码](https://github.com/boreshkinai/any-quantile)。仅作为直接分位数监督可与骨干分离的近期依据；不把其电力结果外推成测井收益。

## 第一优先：物理值轴上的恒等初始化样条传输

**推测机制**：现有 logmass 修补在已有 bin 质量上乘一个有界比例，难以把几乎为零的质量区域变成合理峰值。改为 Y_new=T_h(Y_old)，对现有连续分布的质量做位置传输。CDF 为 F_new(y)=F_old(T_h^{-1}(y))，bin 质量仍是相邻 CDF 差；无需在原目标 bin 的近零概率上直接学习倍率。

- 冻结原模型与默认状态 gate，128→32→(3K−1) 小头，K=8，约 5k 参数。输入仍用原隐藏特征，不叠加历史训练过的修补 checkpoint。
- 等宽等高 knots、导数 1 初始化，零输出层加恒等参数偏置，T(y)=y；尾部为恒等，初始函数保持。建议在当前标准化物理值轴上定义范围，范围仅由训练数据/既有预处理确定。
- 用原解析高斯 CDF 在变换后的有限 bin 边界计算质量，避免从已经 floor/clamp 的离散质量反推 CDF。若用连续 NLL，必须加变换 Jacobian；仅用 bin CE/CDF 分数则直接使用正确 CDF 差。
- 初期只训练真实连续值的条件 bin CE 或既有条件 RPS，不把 gate 的小概率乘入条件学习信号。推理仍用原 gate 和原官方联合动作解码。
- **单因素对照**：同样小头、同 K、同训练信号和种子；只改变变换对象：物理值轴 T(y) versus 概率秩轴 G(F_old(y))。两者均恒等初始化。后者主要调校概率秩，前者可以移动峰的位置；不同时变损失/输入/骨干。
- 可能保护默认状态的理由：gate 和默认原子质量固定。但连续分布的动作效用改变仍可能改变最终默认/连续动作选择，**不保证默认成绩不掉**。记录默认、连续、整体三项实际分数。
- 失败标准：完整早停恢复后，物理传输不胜同容量秩校准且不胜保留 SW 读出，则关闭该局部设计；若连续增益被默认损失完全抵消，不采用。不要继续扫样条深度或 knots 网格。

## 第二优先：强监督分位数新支路，使用固定混合日程

**推测机制**：当前新增分布支路的 sigmoid 混合初值 .001 会压低来自混合 NLL 的梯度。直接训练新支路的分位数风险，不经过混合权重；同时用预先固定的混合日程避免 α 的 sigmoid 导数锁死。它属于一个新增阶段内的联合训练，不是先训练修补再训练第二修补。

- 冻结父模型/gate，128→32→17 的非交叉分位数小头，约 4.7k 参数；累加正间隔形成 17 个 knots。目标只来自真实训练连续标签，不用教师预测当标签。
- 新头直接均匀采样 τ 的 pinball/CRPS 监督，再由单调分位数插值求条件 CDF，转为既有 256 bins；无需依赖原近零 bin 的乘性质量，也不需要高维 flow 或 ODE。
- **初始函数保持办法**：固定 α(0)=0，初始化评估完全使用原分布；在预先规定前 5 轮将 α 增至 .1，之后保持，p=(1−α)p_old+α p_quantile。新头的辅助损失从第 1 轮有完整梯度。注意：epoch 0 函数保持不等于整个训练日程函数保持，日程带来的混合变化必须如实记录。
- **单因素对照**：同分位数头、初始化、α 日程、混合损失与预算，仅辅助分位数监督权重 0 versus 1。先不同时修改空间读出、原骨干或 gate；若当前辅助 CE 实验成功，优先把它作为机制对照而非再次泛扫辅助权重。
- 默认状态质量仍固定，只有连续条件分布变；实际默认动作可能变，必须观察抵消。固定 .1 上限限制新增支路对旧预测的破坏，但仍是预定义经验限制，不是理论保证。
- 失败标准：辅助支路自身条件风险改善而整体官方分不胜无辅助对照/保留版本，则说明优化目标转化为官方效用失败；关闭本结构。若新头风险也不降，检查训练信号/表征之后换方向，不用更大头掩盖问题。

## 选择建议与限制

优先第一项。它在初始函数严格保持、无极小混合梯度、无需随机采样的条件下改变质量的位置，和最近倍率修补的限制更直接对应。第二项更适合当前新增分布辅助监督已有迹象时继续；不应与正在跑的辅助 CE 重复开两个几乎相同任务。

这两项均是本地迁移设计，不是原论文完整复现。没有证据证明可提升 0.175 或达到 80.8。每个目标采用一个完整候选实际组合，保持父模型、固定 split/seed/Q/解码和最多两 GPU，训练上限 80、早停 14。第五折严格超过 80.8 且明确收益后才考虑其他折，未完成五折不声明 >82。
