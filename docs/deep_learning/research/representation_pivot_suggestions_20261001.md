# 从读出修补转向表征：三项有界建议

日期：2026-10-01。仅研究，不启动训练或修改训练代码。主 Agent 提供的当前第五折 TOTAL 为 80.624857，尚未达到 80.8；多种冻结小头、输入旁路及骨干微调只有微小或负收益。下面都是待检验假设，不是已经获得的收益。

共同约束：只用原训练井输入和真实训练标签；不使用教师、外部预训练、伪标签或测试标签。最大 80 轮、现行早停 14、GPU 同时最多 2 个，12 GiB 内运行。候选必须从保留的默认父模型开始，在**一个新增阶段**联合训练所需改动；不能把已训练新增修补 checkpoint 当父节点再追加阶段。已有最佳模型作为控制保留，不覆盖。

## 1. 首选：Rank-N-Contrast 的目标顺序表征监督

原论文：[Rank-N-Contrast: Learning Continuous Representations for Regression，NeurIPS 2023](https://arxiv.org/abs/2210.01189)，[正式论文](https://papers.neurips.cc/paper_files/paper/2023/file/39e9c5913c970e3e49c2df629daff636-Paper-Conference.pdf)，[作者代码](https://github.com/kaiwenzha/Rank-N-Contrast)。

**论文事实**：RNC 按目标空间距离排名构造表征对比监督，研究的是连续回归表征而非概率校准，作者在五个回归数据集上报告效果。论文的理论结论依赖其条件和目标函数，不能直接作为测井保证。

**本任务推测**：真实连续值在当前 hidden 中可能没有形成有用的距离结构；普通 NLL/BCE 容易让默认状态分离占据更多表征能力。仅对连续标签点施加目标距离顺序监督，可能使读出获得更可用的连续信息。这与动作排序损失不同：监督 hidden 的样本间几何关系，而不是最终动作的排名。

**最小实施**：在拟定的共同微调骨干最后一个块的 96/128 维 hidden 上直接计算 RNC，优先不用独立 projector，避免 projector 独自吸收任务而骨干没变化。每训练步最多抽 256 个真实连续点，每井限额、相邻点留最小间距，避免一口井/相邻重复主导；目标距离 SW 用原物理值，PERM 用既有 log10 目标，不拟合验证统计。256² 对比矩阵约 0.25 MiB float32，损失增量很小；不能从所有 8192 点做二次矩阵。

同一次联合微调保留原预测损失；RNC 辅助权重预定义为 0.1。新增参数可为 0。**对照只改 RNC 权重 0 vs 0.1**，更新参数、采样、原损失/预算完全相同。两组都用同一连续点采样，标签仅用于训练损失，不能作为推理选择器。

保留收益：从已保留默认父模型完整函数热启动，旧概率读出不替换；必要的有效修补结构在这一阶段联合训练而非串接训练链。gate 若需固定，必须读取未改变的父 hidden/父 gate，不能只冻结 gate 层却允许其输入改变后声称 gate 不变。

失败停止：完整早停恢复后，RNC 不胜同更新范围的无 RNC 控制即关闭；训练 RNC 改善而连续官方分不改善，说明目标几何与解码不匹配，不继续温度/权重网格。若默认损失抵消连续改善则不采用。不要由一项失败推断所有对比学习无效。

## 2. 次选：遮蔽真实曲线重建作为联合辅助任务

原论文：[Ti-MAE: Self-Supervised Masked Time Series Autoencoders，2023](https://arxiv.org/abs/2301.08871)。

**论文事实**：Ti-MAE 遮蔽嵌入时序并做点级重建，报告时序预测/分类上的表征效果。这里不复制其 Transformer 或独立预训练流程。

**本任务推测**：监督稀疏且连续值占比较小时，重建被遮蔽的九曲线能够给上下文编码持续信号，迫使其利用邻近曲线/深度；但也可能只学习与目标无关的测井幅值，因此应排在 RNC 之后。

**最小实施**：原父模型不变，在同一个新增阶段对选定晚期编码块与原读出共同微调。辅助支路 128→32→9，约 4.4k 参数，仅预测训练输入中真实存在的标准化九曲线，遮蔽位置用训练侧原始输入作为重建标签。辅助权重固定 0.1；未遮蔽原输入走预测损失，遮蔽输入走重建损失，两个 forward 顺序执行，避免两份激活同时持有。

关键泄露风险不是标签，而是**输入捷径**：206 维含原曲线的统计衍生，不可只遮原始九维却把对应衍生保留。最小可用方案是在早期编码得到的 token 上遮连续 8 点左右的 10% spans，让晚期编码块恢复九曲线，并明确这一局部嵌入掩码不能消除所有邻域衍生捷径。若不能合理抑制捷径，放弃实验，不把很低重建误差称为表征改善。

**单因素对照**：两组相同遮蔽 forward/辅助头/参数更新范围，辅助系数 0 vs 0.1；不能同时增宽、加输入、变监督人口。统计用训练拟合，缺失真实曲线不计重建。

失败停止：重建 loss 下降但连续验证官方分和无辅助控制无差别，即关闭；同等训练工作量的墙钟明显增加（预定义 >1.5×）且官方增益仍小于当前读出修补，则优先止损。它不保证默认不掉，仍需三项分层与实际组合。

## 3. 备选：TS2Vec 的重叠上下文一致性

原论文：[TS2Vec: Towards Universal Representation of Time Series，AAAI 2022](https://arxiv.org/abs/2106.10466)，[作者实现](https://github.com/zhihanyue/ts2vec)。

**论文事实**：对增强上下文中的同一时间戳做层级对比，学习点级及子序列表征，并在分类、预测、异常检测上评估。不是要求任意裁剪都具有相同整体语义。

**本任务推测**：同井同深度在不同窗口上下文中的 hidden 不稳定，可能让连续读出学习到窗口边界伪差异。只约束两个窗口重叠中央位置的表征可检验这一问题，比普遍时间平滑更少抹掉真实层界。

**最小实施**：同井两个具有 128 点重叠区的窗口，保留相对深度原值并对齐实际行索引；只在距各边界有充分上下文的同一深度点构造正样本。用现有 hidden 的 32 维训练 projector（128→32 约 4.1k），同时更新选定晚期块，使梯度确实进入推理表征。分别点级与一次 4 点池化层级，不加更深层级；一个 batch 至多 256 对。预测损失仅原视图，另一视图仅辅助，不读模型预测当标签。

本地简化不是完整 TS2Vec：同层相近点可能成为假负例，预定义排除同井近邻 32 点的负样本，跨井负样本仍可能物理相似，需要披露。若没有把握，优先前两项，不用未经验证的全局时序不变性。

**单因素对照**：完全相同双窗口/参数/预算，辅助权重 0 vs 0.1。失败停止：重叠一致性显著改善而官方连续分未改善，关闭；实际总墙钟明显增大且无匹配收益时不继续层级/增强网格。

## 优先次序与证据边界

先 RNC：额外算力最小、与连续标签直接对应、区别于近期概率修补。其次重建，最后上下文对比；不建议三种辅助同时加入，因为无法归因且破坏现有收益更难定位。

这些论文多为 2022–2023 的基础机制，选择依据是可迁移性而非新年份。当前尚无证据证明 hidden 几何碎片化、上下文不稳定或重建缺失就是瓶颈，不能把上述推测当诊断事实。保留完整对照，先固定第五折，达到严格 >80.8 和实测收益后才补折；新结果不得写成完整 OOF >82。
